# C++: 3次元力学モデルレイアウト + 最適視点探索

NSGA-IIによる2次元パレート最適化(`src/bipartite_pareto_layout/`)の初期集団は、良い
出発点があるほど収束が速く・質も安定する。ここでは、単純な2次元ばねモデル
(`nx.spring_layout`)よりも質の高い初期レイアウトを、次の2段階で計算する:

1. **3次元力学モデル(`layout.cpp`)** ── バネ-電荷モデル(原点からの反発 + エッジに沿った
   引力)で全ノードを3次元空間に配置する。2次元より1次元多い分だけ、局所的な重なりを
   避けながら安定した配置に収束しやすい。
2. **視点探索(`sampling.cpp` + `projection.cpp`)** ── フィボナッチ球面サンプリングで
   200個の視点候補を球面上に均等配置し、それぞれの視点から3次元配置を2次元へ正射影する。
   得られた200通りの2次元候補から良いものを選び、NSGA-IIの初期集団(`make_sampling`)の
   種として使う。

反復計算(1000イテレーション×ノード数)と200視点分の投影計算をPythonで行うと
実用的な速度が出なかったため、この部分だけC++で実装し高速化した。

## ビルド

```bash
make
```

(`Makefile`が無い/使えない環境では `c++ -O2 -std=c++17 main.cpp layout.cpp sampling.cpp projection.cpp -o layout3d` で直接ビルド可能)

## 実行

```bash
./layout3d
```

`nodes.csv`(列: `node_id,bipartite,node_type,x,y,z`)・`edges.csv`(列: `src,dst`)を
カレントディレクトリに用意して実行すると、以下を出力する:

- `nodes_3d.csv` ── 1000イテレーション後の3次元配置
- `viewpoints.csv` ── フィボナッチ球面サンプリングによる200視点の候補
- `projections.csv` ── 全視点×全ノードの2次元投影座標
